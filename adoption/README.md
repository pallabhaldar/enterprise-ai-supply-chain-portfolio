# Adoption Evidence

Adoption evidence demonstrates that a contribution was used, relied upon, reused, or recognized beyond its initial creation.

## Document for each contribution

- Adopting organization or authorized anonymized description
- Deployment level
- Number of users, teams, sites, countries, systems, or transactions
- Adoption period and continued-use duration
- Downstream projects or reusable standards
- Training, operational, or governance records
- Name and authority of independent verifier

## Strong supporting records

- Signed client or employer adoption letter
- Production release or change record
- System-generated usage report
- Training or rollout record
- Reference in another team's architecture
- Public citation, fork, reuse, or practitioner reference

Newly authored repository summaries should be treated as explanatory materials, not independent proof of adoption.
