# Architecture Evidence

This directory is reserved for sanitized architectural artifacts that explain the applicant's original technical contribution without exposing protected information.

## Recommended artifact format

Each architecture record should identify:

- Project and original date
- Problem and constraints
- Pallab Haldar's specific contribution
- Proposed architecture
- Alternatives considered
- Review and approval authority
- Deployment outcome
- Reuse or broader adoption
- Independent supporting evidence

## Approval standard

A newly prepared diagram explains a contribution but does not independently prove historical approval. Pair each diagram with an authorized letter, contemporaneous approval record, or governance document.

## Diagram folder

Place only sanitized diagrams in `architecture/diagrams/`. Remove customer names, internal hostnames, system identifiers, credentials, proprietary schemas, and confidential operational details.
