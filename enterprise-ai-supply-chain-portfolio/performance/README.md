# Performance and Validation Evidence

Performance evidence should allow an informed reader to understand what was measured, how it was measured, and who can verify the result.

## Required fields

- Project and evaluation period
- Dataset size and provenance
- Training, validation, and test design
- Metric definition
- Baseline result
- Proposed-method result
- Statistical or operational uncertainty
- Business outcome, reported separately from model performance
- Independent verification source

## Evidence integrity

Do not report a percentage without defining its denominator and calculation. Do not present model accuracy as a business-cost reduction, or correlation as proof that the model caused the operational result.

## Charts

Place sanitized, reproducible charts in `performance/charts/`. Each chart should contain a title, axis labels, unit, date range, source note, and methodology reference.
