## Evidence Integrity Rules

- Distinguish prototype, proof of concept, pilot, limited production, full production and enterprise-standard adoption.
- Separate the original project or decision date from the repository publication date.
- Define every performance metric, dataset, evaluation period, baseline and calculation.
- Do not publish confidential customer data, source code, credentials, internal URLs or proprietary system details.
- Mark unsupported or incomplete information as **To be verified**.
- Treat newly written summaries as explanatory exhibits, not independent proof of historical deployment or impact.
